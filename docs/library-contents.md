# Downloaded library: what's on the PC

The PDFs themselves are **not** in this repo (about 1.45 GB, 395 PDFs). They live on the PC at `C:\Users\tamil\Documents\INStudy_Library`. To rebuild the library on any computer, run `study-library/get_study_pdfs.py`.

This list comes from the downloader script. NCERT books arrive as one folder per book, with one PDF per chapter.

Note: NCERT has retired the old Class 9 History, Geography, Democratic Politics and Economics books. The library has the new two-part Class 9 book *Understanding Society: India and Beyond* in their place, in `01_Foundation_NCERT_6-10`.
